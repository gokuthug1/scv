Engineering Highlights

Engineered for deep frontend inspection

Source Code Viewer combines the convenience of an extension popup with the depth of a full desktop developer IDE.

Source Map Auto-Unbundling

Automatically resolves sourceMappingURL declarations. Fetches production maps and reconstructs original source file hierarchies directly into readable developer directories.

Credential & Secret Scanner

Audits client-side scripts for exposed credentials including Stripe live keys, AWS Access Keys, Google API keys, OpenAI tokens, and hardcoded JWTs with context-aware line snippets.

Clean PKZIP Site Downloader

Packages all extracted scripts, stylesheets, inline blocks, SVGs, and state snapshots into standard ZIP files with sanitized relative paths, bypassing browser download throttling.

Three Flexible Operating Modes

Inspect code the way you prefer: in a compact toolbar popup, a dedicated independent floating window, or docked into Chrome's native Side Panel alongside your active tab.

Snapshot Line Diffing

Save extraction snapshots to IndexedDB. Re-extract pages later to run linear-time diffs that immediately highlight added, changed, or deleted code lines across releases.

Framework & Stack Detection

Automatically identifies frontend frameworks (React, Vue, Angular, Svelte, Next.js, Nuxt) and utility ecosystems (Tailwind CSS, Bootstrap, Vite, Webpack) from bundle signatures.

Cloud & Desktop Workflows

Export to your favorite development tools

Move from in-browser inspection to active debugging in a single click.

VS Code Desktop

Generates clone URIs or structured project bundles for opening directly in Visual Studio Code on your machine.

VS Code Web (vscode.dev)

Launches repositories and unbundled scripts into the lightweight browser edition of VS Code with full keybindings.

CodePen & JSFiddle

Exports extracted HTML, CSS, and JS snippets directly into blank sandbox pens for rapid UI experimentation.

GitHub Gist

Publishes multi-file inspection snapshots straight to your GitHub account using a personal access token stored safely in sync storage.

Private by Design & Zero Telemetry

Everything runs strictly inside your local browser runtime.

Zero Remote Code (`eval` Free)

Complies strictly with Manifest V3 security requirements. All JavaScript, CSS, and lexers are bundled offline inside the extension.

Ephemeral Content Handling

Extracted page content stays on your machine. No code, URLs, or cookies are ever transmitted to third-party tracking services or external databases.

IndexedDB & Web Worker Offloading

Large multi-megabyte bundles are processed in separate Web Worker threads and stored natively in browser IndexedDB to prevent main-thread UI locking.

Direct User-Initiated API Calls

Network calls are only dispatched to external services (like GitHub Gist or CodePen) when you explicitly click the respective export action button.

Source Code Viewer — Privacy Summary

1. Zero Data Collection & Zero Telemetry

Source Code Viewer does not collect, store, transmit, or sell any personal data, browsing history, user identities, IP addresses, or keystrokes. The extension contains no tracking scripts, no analytics SDKs, and no remote advertising pixels.

2. 100% Local In-Browser Processing

All source code extraction, syntax highlighting, beautification, credential auditing, source map unbundling, and ZIP packaging is executed entirely within your browser's local sandbox using client-side JavaScript, IndexedDB, and Web Workers.

3. User-Initiated Third-Party Exports

If you choose to use third-party export features (e.g. CodePen, JSFiddle, StackBlitz, VS Code for Web, or GitHub Gists), only the specific code snippets you choose to export are transmitted directly to the respective third-party platform under your own direction.

4. Permissions Usage

Permissions such as activeTab, scripting, downloads, storage, and sidePanel are requested strictly to perform code extraction, file downloading, theme persistence, and side-panel docking on behalf of the user.
